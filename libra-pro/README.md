# LibraPro - Complete Premium Library Management System

Full-featured professional Library Management Software.

## Complete Features
- Premium glassmorphism dashboard with charts
- Role-based access + Register/Login with CSRF
- Books CRUD + detail + CSV import
- Categories & Authors management
- Members + member history + printable member card
- Issue / Return with fines + fine payment system
- Due date extension
- Overdue tracking + PDF report
- Reservations
- Barcode scanning
- CSV Export + PDF receipts
- Notifications
- Activity logs
- Settings
- User management

## Default Login
- Username: `admin`
- Password: `admin123`

## Run
```bash
cd libra-pro
pip install -r requirements.txt
python app.py
```
Open http://localhost:5000
